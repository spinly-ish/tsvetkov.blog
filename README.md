# tsvetkov.blog

Персональный блог — учебный проект для изучения React.

## 🎯 Цель проекта

Поэтапное изучение React через создание персонального блога, начиная с простого HTML/CSS и постепенно усложняя до полноценного React-приложения с бэкендом.

## 🚀 Запуск

### Stage 1 (текущий)
Просто откройте `index.html` в браузере или используйте любой локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен npx)
npx serve
```

## 🌐 Деплой

### GitHub Pages
1. Push код в репозиторий
2. Settings → Pages → Source: main branch
3. Сайт будет доступен по адресу: `https://username.github.io/tsvetkov.blog`
